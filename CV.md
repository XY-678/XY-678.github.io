## Research interests

Zero-knowledge proofs, verifiable machine learning (zkML), and distributed proof generation. I am particularly interested in how multiple machines can jointly prove a single virtual machine execution while enforcing memory consistency across the computation.

## Selected research activities

- **Verifiable neural network inference.** Studied how zkCNN represents two-dimensional convolution as a polynomial computation and uses sumcheck and the GKR protocol to verify intermediate results.
- **Distributed proving for virtual machines.** Examined how Pianist distributes PLONK proving across machines. I am exploring how its cross-machine permutation checks could support memory consistency in a distributed zkVM.
- **Proof systems for program execution.** Studied how Cairo encodes CPU steps and memory accesses as algebraic constraints and how FRI checks proximity to a low-degree polynomial in STARK proof systems.
