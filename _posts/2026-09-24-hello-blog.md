# 博客搭建记录

欢迎来到我的个人博客！这是网站上线时创建的一篇**示例文章**，之后可以自由修改或删除。

这里可以记录学习笔记、项目实践，以及日常遇到的技术问题。

## 如何发布下一篇文章？

在 GitHub 仓库的 `_posts` 文件夹中新建一个 Markdown 文件，名称格式为：

`YYYY-MM-DD-文章英文名.md`

文章开头需要包含类似下面的内容：

```yaml
---
layout: default
title: "我的第二篇文章"
date: 2026-09-25 10:00:00 +0800
description: "用一句话介绍这篇文章"
---
```

下面直接使用 Markdown 编写正文即可。提交到仓库的 `main` 分支后，GitHub Pages 会重新生成网站，首页也会自动出现新文章。
